使用场景

以下场景描述的是常见用法，具体线路能力请以你所选套餐的说明为准。

01

远程协作与资料

打开海外文档、代码托管或协作平台时，先在客户端里连上常用线路，再进入工作流。把加速当成开机后的一层网络习惯，比反复开关更省事。

适合这样开始

只把需要出海的浏览器或应用走代理，本地网盘、内网与银行类应用保持直连。分流规则在客户端中设置，龙猫云负责提供可导入的订阅。

02

内容访问与公开课

检索公开课、软件源或地区受限的公开内容时，用订阅更新后的节点列表按目标站点切换。先看套餐是否覆盖你的目标类型，再决定是否升级。

不要把所有流量一股脑送进代理

全量代理会拖慢本地访问，也更难排查问题。客户端选择阶段就要确认：它能否按应用或按域名分流，这比外观更重要。

03

小团队共用

多人协作时，用一份订阅减少各自找线路的时间。设备数量以套餐模块写明的上限为准，超限前应改套餐或错峰使用，而不是反复重装客户端。

游戏与实时会话

若你关心对局或会议延迟，连接后以实际表现为准，并阅读套餐中关于加速优化的原文。本页不承诺固定延迟数值。

重点

客户端选择

龙猫云的使用体验很大程度取决于客户端是否匹配系统、能否粘贴订阅、能否分流。先锁定操作系统，再看导入方式，最后才看界面偏好。请通过下方模块中的真实链接获取应用，避免在来路不明的页面下载安装包。

电脑端怎么选

Windows 与 macOS 适合规则更细的图形客户端：需要能订阅更新、节点分组，以及把浏览器与通讯软件分开走代理。安装完成后先导入订阅，再开系统代理。

手机端怎么选

iOS 与 Android 优先选能后台保活、支持订阅刷新的应用。移动网络下先连再打开目标 App。若系统对未签名应用有限制，只使用客户端模块标明的获取方式。

四个判断题

  • 安装包是否对应你的系统版本
  • 能否直接粘贴订阅地址
  • 是否支持分应用或规则分流
  • 节点列表更新是否一键完成

导入后先做的两件事

更新订阅，确认节点名称出现在列表中；用浏览器访问一个明确需要加速的站点做连通检查。失败时回到步骤说明，而不是频繁更换来源不明的安装包。

操作说明

五步走通

  1. 在套餐区确认流量与同时在线设备。
  2. 完成订购后，在账户中复制订阅地址。
  3. 回到客户端区，按系统打开对应应用说明并安装。
  4. 于客户端粘贴订阅、更新节点列表。
  5. 选择节点连接，用目标网站验证；需要时再设置分流。

导入失败时

检查订阅是否被截断、客户端是否为当前系统版本、本地时间是否准确。仍失败则更换同一系统下的备选客户端，而不是修改订阅内容。

日常维护

流量告急或设备不够用时，回到套餐模块对照原文升级或续费。客户端只需保留一个常用版本，避免多开冲突。

常见问题

龙猫云是什么？和普通浏览器插件有何不同？

龙猫云是机场订阅型网络加速服务：你在官网选定套餐后获得订阅，再导入到电脑或手机上的加速器客户端中连接。它面向需要持续跨境访问的使用方式，而不是一次性网页跳转。具体线路与流量以套餐模块为准。

我应该怎样选择客户端？

先看操作系统，再看能否粘贴订阅、能否分流、能否更新节点。电脑端适合规则更细的配置，手机端优先后台稳定。请只使用本页客户端模块提供的入口下载，这是选择阶段最重要的安全步骤。

第一次使用的完整顺序是什么？

阅读场景确认需求 → 在套餐区下单并复制订阅 → 按系统安装客户端 → 导入并更新节点 → 连接后访问目标站点验证。五步缺一都会在「能打开软件却连不上」时难以排查。

可以同时在多台设备上使用吗？

可以，但同时在线数量以你所选套餐的原文说明为准。超出上限时，应升级套餐或关掉闲置设备上的连接，而不是反复重装客户端。

订阅导入失败或节点列表空白怎么办？

确认订阅整段复制、客户端版本匹配系统、设备时间正确，然后手动更新一次订阅。若仍空白，换用同一系统下模块中的另一款客户端。不要在陌生网站重新获取所谓「加速器破解版」。
